🌦️ Real-Time Air Quality & Weather Analytics Dashboard
🚀 Project Overview
A high-performance Power BI dashboard providing real-time weather insights and Air Quality Index (AQI) monitoring. This project focuses on Advanced Data Visualization, featuring a custom Glassmorphism UI and a dynamic Neon Theme Toggle.

✨ Key Features
7-Day Predictive Analytics: Integrates historical and 7-day forecast data for temperature and air quality trends.

Real-Time Pollutant Monitoring: Tracks 6 key pollutants (PM10, PM2.5, SO2, NO2, CO, O3) with custom DAX-driven status indicators.

Interactive UI/UX: * Dual-Mode Toggle: Seamlessly switch between Neon Blue and Vibrant Orange themes using Bookmarks and Actions.

City Navigation: Integrated buttons for quick location switching (Colombo, Galle, Jaffna).

Live API Integration: Fetches data dynamically from the Open-Meteo API, ensuring up-to-the-minute accuracy.

🛠️ Technical Stack & Skills
Power BI Desktop: Advanced report authoring and UI design.

DAX (Data Analysis Expressions): Created complex measures for AQI status dots and dynamic KPI cards.

Power Query (M Language): Extracted and transformed JSON data from REST APIs into a clean relational model.

UI/UX Design: Implemented Glassmorphism, neon color accents, and transparent backgrounds for a modern aesthetic.
